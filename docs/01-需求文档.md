## 1. 项目背景与目标

### 1.1 现状痛点（来自需求方原话提炼）

1. 每次拍摄结束后，需要把内存卡中的照片、视频拷贝到文件服务器；
2. 每次拷卡都要**手动在服务器上新建文件夹 → 手动复制文件 → 复制完再手动格式化内存卡**；
3. 素材缺乏**项目化管理**，时间久了很难按"哪次拍摄 / 什么类型 / 在哪里拍的"找回素材；
4. 希望软件**轻量化**、尽量使用 Windows 原生组件，同时**界面要好看**。

### 1.2 产品目标

| 编号 | 目标 | 可量化的判定标准 |
|------|------|------------------|
| G1 | **插卡即自动**：从插卡到素材落盘，无需手工建目录、手工复制 | 插卡后点击 1 次即可完成；全自动模式下 0 次 |
| G2 | **数据绝对安全**：拷贝可验证，格式化有护栏 | 每次任务都有校验清单与日志；对系统盘/内置盘/网络盘格式化的可能性为 0 |
| G3 | **素材项目化**：每次拍摄 = 一个带时间/地点/类型的项目 | 项目库可按时间、地点、类型检索；项目目录内自带说明文件，直接看 NAS 也能读懂 |
| G4 | **轻量美观**：绿色免安装、占用低、界面现代 | 程序目录 < 5 MB；空闲内存 < 120 MB；支持深/浅色主题与 125%/150% DPI 缩放 |

### 1.3 范围界定

- **本期（V1.0）实现**：F01 ~ F16（见第 3 章）。
- **本期不做**：见第 8 章。

### 1.4 典型使用场景

**场景 A · 婚礼当天回传**
拍完婚礼回到工作室 → 插入 CFexpress 卡 → 软件 3 秒内识别并显示"3,842 个文件 / 268 GB / 照片 + 视频" →
点击"开始拷贝" → 自动在 NAS 创建 2026 下的 2026-03-10_婚礼_上海外滩 目录 →
并行拷贝并实时显示速度与剩余时间 → 完成后自动校验 → 提示"校验通过，可格式化" →
确认后快速格式化卡片 → 提示可以拔卡。全程约 3 次点击。

**场景 B · 三个月后找素材**
客户要"去年在杭州拍的那场商业活动" → 打开项目库 → 类型 = 商业产品、地点 = 杭州、时间 = 2025 筛选 →
双击项目 → 直接打开素材目录，并看到当时的相机型号、卡号、文件数量与校验状态。

**场景 C · 双备份**
重要商业拍摄，设置中开启多目标备份 → 一份写入 NAS 素材盘，一份写入本地移动硬盘 →
两个目标都校验通过才判成功；任一失败标为"部分成功"并给出单独重试入口。

## 2. 术语表

| 术语 | 含义 |
|------|------|
| 源 Source | 内存卡上的素材目录，通常是 DCIM、PRIVATE、AVCHD 等 |
| 目标根 Target Root | 素材存放的服务器根目录，如 Z:\ 或 UNC 路径 |
| 项目 Project | 一次拍摄对应的一条记录 + 一个磁盘目录 |
| 项目目录 | 自动创建的目录，如 2026 下的 2026-03-10_婚礼_上海外滩 |
| 拷贝计划 Copy Plan | 拷贝前生成的待拷贝文件清单（源路径、目标路径、大小、动作） |
| 校验清单 Manifest | 拷贝后生成的文件级校验记录（大小 + 哈希），用于证明数据完整 |
| 快速格式化 | 只重建文件系统、不逐扇区擦除，秒级完成 |
| 全自动模式 | 插卡后按预设规则自动完成拷贝与校验（格式化为独立开关） |

## 3. 功能需求

优先级：**P0** = V1.0 必须；**P1** = V1.0 尽量；**P2** = 后续版本。M 编号对应开发步骤清单中的里程碑。

### F01 · 存储卡自动识别与监听【P0 / M2】

- **功能描述**：软件常驻监听 USB 设备插拔，插入内存卡（或读卡器）后 3 秒内识别出可用卡片并展示卡片信息；拔出后自动移除并停止相关任务。
- **目的**：替代"打开资源管理器找盘符"的动作，让流程从插卡开始，而不是从找盘开始。
- **效果**：
  1. 插卡后主界面出现卡片面板，显示盘符、卷标、文件系统、总容量、可用容量、是否含 DCIM；
  2. 同时插入两张卡时分别列出，可分别操作；
  3. 拔卡时面板置灰提示"卡片已移除"，正在运行的任务自动暂停并明确提示（不静默失败）；
  4. 已拷贝中的卡片拔掉后重新插回，可继续拷贝（见 F12 断点续传）。
- **兼容性要求**：CFexpress / XQD 读卡器常被 Windows 报告为"固定磁盘"，判定必须综合"是否含 DCIM / M4ROOT / AVCHD / XDROOT 目录 + 非系统盘 + 外接总线"，不能只看可移动标志。
- **验收要点**：插拔 10 次识别成功率 100%；识别耗时 < 3 秒；不会把系统盘或网络盘误判为卡片。

### F02 · 卡片内容扫描与分析【P0 / M2】

- **功能描述**：识别到卡片后自动扫描素材并按类型分类统计，给出本次拍摄的基本判断。
- **目的**：拷卡前先知道"卡里有什么、有多大"，避免拷错卡或拷到一半发现空间不足。
- **效果**：
  1. 统计面板显示照片数量与大小、视频数量与大小、其他文件数量与大小、总计；
  2. 显示素材时间范围（如 2026-03-10 09:12 ~ 18:40），用于提示"这是一次拍摄"；
  3. 显示识别到的相机型号，识别不到则显示"未知"；
  4. 扫描有进度显示，50 GB 卡片扫描 < 10 秒（仅枚举元数据，不读内容）；
  5. 自动忽略系统文件（System Volume Information、.Trashes、Thumbs.db、.DS_Store）与 0 字节文件（可在设置中调整）。
- **验收要点**：统计数字与实际文件数一致；扫描全程只读，不修改卡上任何内容。

### F03 · 项目自动命名与目标路径规划【P0 / M3】

- **功能描述**：按"拍摄时间 + 拍摄类型 + 地点"自动生成项目目录名与服务器路径，无需手工新建文件夹；命名模板可自定义。
- **目的**：直接消灭"手动创建文件夹"这一痛点，并让目录名自带语义。
- **效果**：
  1. 默认命名：年份目录 + 日期_类型_地点，例如 2026 下的 2026-03-10_婚礼_上海外滩；
  2. 拷贝前界面显示"将要创建：Z: 2026 2026-03-10_婚礼_上海外滩"，各字段可一键修改；
  3. 命名自动清洗：Windows 非法字符、首尾空格与点、超长（> 120 字符）自动处理；
  4. 目录已存在时按设置处理：自动追加序号 _2 / 合并进已有目录 / 询问；
  5. 可选内部子目录结构：照片、视频、其他（照片再按 RAW 与 JPG 分层），默认开启按类型分目录；
  6. 地点与类型支持历史记忆与预设列表，减少每次输入。
- **验收要点**：模板变量替换 100% 正确；含中文、空格、emoji 的地点名都能正确创建目录。

### F04 · 高性能并行拷贝引擎【P0 / M3】

- **功能描述**：把内存卡素材拷贝到目标目录，多文件并行、大文件分块，全程可视化。
- **目的**：替代"资源管理器里拖拽 + 苦等 + 不确定拷没拷完"的过程，速度不劣于手动复制。
- **效果**：
  1. 显示总进度条、已完成与总大小、实时速度（MB/s）、剩余时间（ETA）、当前文件；
  2. 支持暂停 / 继续 / 取消；取消后已拷文件保留，任务可重试；
  3. 保留原始文件时间戳（拍摄时间不改变）；
  4. 拷贝速度不低于同环境资源管理器复制的 95%；
  5. 兼顾 GB 级单文件（视频）与数万个小文件（RAW + JPG）两种极端场景；
  6. 目标空间不足时在拷贝前阻止，并明确提示"需要 X GB，可用 Y GB"。
- **验收要点**：拷贝后文件数与字节数与源一致；时间戳一致；中途取消不产生半截文件（先写临时文件再原子改名）。

### F05 · 数据完整性校验【P0 / M3】

- **功能描述**：拷贝完成后校验目标与源是否一致，提供四档校验强度。
- **目的**：拷卡最怕"看起来拷完了但文件是坏的"，用机器校验替代人工抽查。
- **效果**：
  1. 四档：① 不校验 ② 大小校验 ③ 快速哈希 CRC32 ④ SHA-256 强校验；
  2. 默认档位：**大小 + 抽样哈希**（每文件首 1 MB + 尾 1 MB + 中点 1 MB）；
  3. 校验失败的文件标红并进入"失败清单"，可一键重拷；
  4. 校验有独立进度条，可取消。
- **验收要点**：人为篡改目标文件 1 字节，档位 ③ ④ 必须检出；档位 ② 允许漏检（界面已注明差异）。

### F06 · 校验清单与拷贝报告【P0 / M3】

- **功能描述**：每次拷卡在项目目录内生成机器可读的校验清单与人类可读的报告。
- **目的**：留下"这次拷贝是否完整"的凭据，日后排查素材损坏时有据可依。
- **效果**：
  1. 生成 _manifest.json：源卡标识、拷贝时间、文件列表（相对路径、字节数、哈希、修改时间）、校验档位与结果；
  2. 生成 _project.json：拍摄时间、地点、类型、相机型号、卡卷标、文件统计、备注（跨机器可读）；
  3. 生成 _copy.log：本次任务完整文本日志；
  4. 界面支持"复制报告摘要"与"导出 CSV"。
- **验收要点**：清单文件可被软件重新解析校验（对应"重新校验项目"功能）。

### F07 · 拍摄项目元数据管理【P0 / M4】

- **功能描述**：每次拷贝自动创建一个"项目"，记录拍摄时间、地点、拍摄类型，并支持人工补充与修改。
- **目的**：满足"项目式管理素材"的核心诉求，让素材带上下文。
- **效果**：
  1. 字段：项目名、拍摄日期（默认取素材时间范围）、地点（输入 + 历史下拉）、拍摄类型（预设下拉 + 自定义）、摄影师、相机型号（自动识别）、客户与备注（可选）；
  2. 拍摄类型预设：人像写真、婚纱婚礼、活动会议、商业产品、风光旅行、体育运动、新闻纪实、视频摄制、航拍、其他；
  3. 项目创建后可在项目库中随时编辑，编辑后同步更新服务器上的 _project.json；
  4. 提供快速模式：拷贝前只填地点与类型，其余自动推断。
- **验收要点**：字段重启后仍存在；改地点后服务器上的 _project.json 同步更新。

### F08 · 项目库管理与检索【P0 / M5】

- **功能描述**：以列表形式管理全部历史项目，支持筛选、搜索、统计与常用操作。
- **目的**：让"找素材"从"翻文件夹猜名字"变成"检索项目"。
- **效果**：
  1. 列表显示项目名、日期、地点、类型、文件数、总大小、校验状态、目标路径；
  2. 支持按时间范围、地点、类型筛选，按项目名、备注、相机型号关键词搜索；
  3. 支持排序（日期 / 大小 / 名称）与统计摘要（如"2026 年共 42 个项目，8.6 TB"）；
  4. 行内操作：打开目录、复制路径、查看清单、重新校验、编辑元数据、删除记录（不删磁盘文件，需二次确认）；
  5. 提供"从服务器重建项目库"：扫描目标根目录下的 _project.json 恢复记录（换机或重装系统后可用）。
- **验收要点**：500 个项目下列表滚动流畅；搜索响应 < 300 ms。

### F09 · 任务历史与日志审计【P0 / M4】

- **功能描述**：记录每一次拷卡任务的完整过程，提供可查询的历史页面。
- **目的**：出问题时能自证"当时发生了什么"，也便于统计工作节奏。
- **效果**：
  1. 记录：任务时间、卡片卷标、文件数、总大小、目标路径、耗时、平均速度、校验结果、格式化结果、成功/失败/部分成功；
  2. 失败任务提供重试、查看失败清单、打开日志入口；
  3. 日志按天滚动，默认保留 90 天（可设置），单文件不超过 10 MB；
  4. 全部本地存储，不做任何上传。
- **验收要点**：任务失败时日志含可定位的错误码与异常摘要。

### F10 · 安全格式化与清空卡片【P0 / M6】

- **功能描述**：在**校验通过之后**提供一键快速格式化；同时提供更保守的"清空卡片文件"选项。
- **目的**：消灭"最后手动格式化"这一步，同时绝不因自动化而威胁数据安全。
- **效果**：
  1. 只有本次拷贝与校验全部成功后，格式化按钮才解锁；未成功的卡片无法格式化；
  2. 二次确认：默认弹窗确认；可在设置中开启"校验通过后自动格式化（10 秒倒计时可取消）"；
  3. 硬性护栏（不可关闭）：只允许对 USB / 外接总线磁盘执行；禁止对系统盘、任何内置固定磁盘、网络驱动器、光驱执行；目标卡必须在本软件已成功拷贝的清单内；
  4. 格式化默认沿用卡片原有文件系统与卷标，可自定义；
  5. "清空卡片文件"：删除素材文件但保留文件系统结构，适合不愿格式化的场景；
  6. 格式化完成后重新读取卡片信息确认成功，并提示可以安全拔卡。
- **验收要点**：对系统盘、网络盘、内置固定盘尝试格式化均被拒绝并给出原因；对真实卡片格式化成功率 ≥ 99%（失败时给出明确原因，如卡片被 Windows 资源管理器占用）。

### F11 · 多目标备份【P1 / M6】

- **功能描述**：一次拷贝同时写入两个（或更多）目标，例如 NAS + 移动硬盘。
- **目的**：商业拍摄的双备份需求，避免单点故障。
- **效果**：
  1. 设置中配置主目标与副目标（副目标可留空）；
  2. 两个目标分别显示进度与校验结果；
  3. 全部成功 = 成功；部分成功标红并允许单独重试失败目标；
  4. 副目标断开不影响主目标完成，只在汇总时报告。

### F12 · 断点续传与失败重试【P1 / M4】

- **功能描述**：任务中断（拔卡、断网、软件退出、异常断电）后可原地继续，不必从头再来。
- **目的**：避免 GB 级素材重复拷贝，浪费时间与卡寿命。
- **效果**：
  1. 拷贝前生成计划文件，完成一个文件记录一个；
  2. 恢复时跳过"已存在且大小一致"的文件（可在设置中改为强制重拷）；
  3. 网络目标断开时自动暂停并每 15 秒重试连接，恢复后自动继续；
  4. 单文件失败自动重试 3 次（退避 1s / 3s / 9s）。

### F13 · 设置中心【P0 / M6】

- **功能描述**：集中管理全部可配置项，持久化到本地文件。
- **效果**：至少包含以下分组（字段清单见技术文档 §3.2）：
  1. **目标**：主 / 副目标根目录、命名模板、内部子目录结构；
  2. **拷贝**：并行数（1–8，默认 4）、缓冲区大小、冲突策略、是否跳过非媒体文件、是否保留目录结构；
  3. **校验**：校验档位、是否校验视频、失败处理策略；
  4. **卡片**：识别规则、忽略目录与文件模式、格式化默认文件系统、是否自动格式化及倒计时；
  5. **界面**：主题（浅色 / 深色 / 跟随系统）、强调色、字体大小、最小化到托盘、开机自启；
  6. **数据**：日志保留天数、项目库位置、导入 / 导出配置。
- **验收要点**：改动立即生效并持久化；配置文件损坏时回退默认值并提示，不崩溃。

### F14 · 系统托盘与通知【P1 / M6】

- **功能描述**：关闭窗口默认最小化到托盘；任务完成或失败时给出系统通知与提示音。
- **目的**：拷卡耗时长，用户希望期间去做别的事，结束时能被叫回来。
- **效果**：
  1. 托盘右键菜单：显示主界面、暂停当前任务、弹出卡片、退出；
  2. 任务完成 / 失败弹出 Windows 通知，含结果摘要；
  3. 托盘图标可选显示任务进度。

### F15 · 现代化界面与交互【P0 / M5】

- **功能描述**：轻量、美观、符合 Windows 11 视觉习惯的界面。
- **目的**：满足"要好看"的明确要求，同时保留原生组件的轻量优势。
- **效果**：
  1. 布局：左侧导航（卡片 / 项目库 / 历史 / 设置 / 关于）+ 右侧内容区，顶部为当前卡片与主要动作；
  2. 视觉：圆角卡片、微软雅黑字体、深浅色主题、跟随系统强调色、细腻的悬停与阴影反馈；
  3. 交互：支持拖拽文件夹指定源、快捷键（F5 刷新、Ctrl+Enter 开始、Esc 取消）、耗时操作一律有进度且可取消；
  4. 高 DPI：100% / 125% / 150% / 200% 缩放不模糊、不重叠；
  5. 窗口记忆上次大小与位置；UI 线程不执行耗时 I/O，长任务不假死。
- **验收要点**：四种缩放下无错位；长任务期间界面可正常操作。

### F16 · 便携部署与运行环境【P0 / M1】

- **功能描述**：绿色免安装，单目录拷贝即可运行；数据可随程序目录走（便携模式）。
- **目的**：满足"轻量化"要求，避免安装器与注册表污染。
- **效果**：
  1. 程序目录 < 5 MB，无外部依赖安装（仅依赖 Windows 自带的 .NET Framework 4.8，Win10 1809+ 与 Win11 均自带）；
  2. 双击 exe 即可运行，不需要管理员权限；
  3. 数据目录可选：程序目录（便携）或 %APPDATA%（默认）；
  4. 开机自启写入当前用户启动项，不写系统服务。
- **验收要点**：整个程序目录复制到另一台 Win11 电脑可直接运行。

## 9. 风险与依赖
