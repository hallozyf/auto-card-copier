# 自动拷卡助手（AutoCardCopier）

给摄影师用的 Windows 桌面软件：**插入内存卡 → 自动拷贝到文件服务器 → 自动校验 → 可选自动格式化**，并按"拍摄时间 + 地点 + 拍摄类型"对每次拍摄做项目化管理。

## 特性一览

- 插卡自动识别（兼容被 Windows 识别为"固定磁盘"的 CFexpress / XQD 读卡器）
- 拷贝前自动生成项目目录，命名模板可自定义
- 并行拷贝，实时显示速度与剩余时间，可暂停与取消
- 四档完整性校验（不校验 / 大小 / CRC32 / SHA-256，默认大小 + 抽样）
- 每次拷贝自动生成校验清单与项目元数据，可直接在 NAS 上查看
- 项目库检索（按时间、地点、类型、关键词）
- 断点续传：拔卡、断网、断电后可继续
- 安全格式化：六条硬性护栏，只有成功拷贝并校验通过后才可执行
- 绿色免安装，程序目录不到 5 MB，依赖 Windows 自带 .NET Framework 4.8

## 开发环境（本机已实测）

| 项目 | 说明 |
|------|------|
| 目标框架 | .NET Framework 4.8（Windows 自带，无需安装） |
| 编译器 / 构建 | Visual Studio BuildTools 中的 MSBuild 18 与 Roslyn |
| 第三方依赖 | 无（不使用任何 NuGet 包） |
| 版本控制 | 便携 Git，位于 tools/git |
| 测试 | 自研控制台测试运行器 |

## 构建与运行

```powershell
# 构建
.\build\build.ps1 -Configuration Release

# 运行测试
.\build\run-tests.ps1

# 运行程序
.\build\out\AutoCardCopier.App.exe
```
